POCArchitect Quickstart Redirect

This former quickstart duplicated command and option details that are now
generated or maintained in canonical documentation. Use:

  docs/NOVICE_USABILITY_GUIDE.md

The canonical guide contains supported Windows PowerShell and Bash installation
paths, provider setup, batch recovery, exact success indicators, and
troubleshooting.

Safe no-clone, no-provider-call preview from the repository root:

  python -m pocarchitect --url https://github.com/example/poc --no-ingest --dry-run --format json --no-color

For the current option surface, use docs/cli-reference.md or run:

  python -m pocarchitect --help
